Profil & Pendekatan Berkarya

Saya adalah mahasiswa D4 Teknologi Rekayasa Multimedia di Politeknik Elektronika Negeri Surabaya (PENS). Sebagai seorang calon Multimedia Content Creator, fokus utama saya terletak pada eksplorasi ilustrasi digital, desain grafis, serta penyusunan aset visual untuk berbagai media kreatif dan interaktif.

Dalam proses berkarya, saya terbiasa menggunakan tools seperti Adobe Illustrator, Inkscape, Ibis Paint, dan Canva, serta memanfaatkan Ren'Py dan Visual Studio Code untuk pengembangan proyek berbasis visual novel. Saya senang menyelesaikan masalah komunikasi visual—mulai dari menyusun komposisi bentuk dan warna yang harmonis, merancang aset grafis yang rapi untuk kebutuhan tim, hingga menghidupkan narasi visual agar pesan dapat tersampaikan dengan jelas dan menarik kepada audiens.

Visual Novel "Asal Usul Tradisi Nyadran di Desa Ketingan"

Proyek media interaktif bertema kearifan lokal yang mengemas sejarah dan nilai tradisi Nyadran ke dalam format permainan visual novel. Menggabungkan pembuatan aset visual mandiri, navigasi dialog bercabang, 3 mini games selingan, dan tata suara yang imersif.

Problem: Menyampaikan cerita tradisi lokal agar tetap menarik, interaktif, dan mudah dipahami oleh generasi muda tanpa terasa monoton seperti membaca literatur biasa.
Solution: Mengonversi narasi ke format visual novel interaktif dengan tombol respon pilihan cerita, 3 mini games pendukung, serta musik latar (BGM) dan efek audio (SFX) yang membangun atmosfer.
Kontribusi Saya: Membuat aset karakter & background, menulis script kode Ren'Py di VS Code untuk fungsi tombol interaktif, menyempurnakan 3 mini-games, serta mencari dan menambahkan musik latar dan efek audio ke dalam game.

Eksplorasi Desain Vektor "Supergraphic"

Eksplorasi desain grafis berbasis vektor menggunakan bentuk-bentuk geometris dasar untuk menciptakan komposisi visual skala besar yang dinamis, berani, dan harmonis sebagai elemen pendukung identitas visual.

Problem: Menciptakan komposisi visual yang dinamis dan berenergi hanya menggunakan bentuk geometris dasar tanpa kehilangan rasa keteraturan dan kesatuan.
Solution: Menyusun perpotongan elemen lingkaran, setengah lingkaran, persegi, dan persegi panjang dengan harmoni warna hangat-dingin: kuning, oranye, merah, merah muda, dan ungu.
Kontribusi Saya: Perancangan konsep bentuk geometris, penataan tata letak berpotongan (layering), peracikan palet warna, dan finalisasi berkas vektor di Inkscape.

Aset Visual Animasi 2D "Kolaborasi Tanpa Batas"

Pembuatan materi aset visual berbasis grafis vektor untuk mendukung kebutuhan pipeline produksi proyek animasi 2D bertema "Kolaborasi Tanpa Batas".

Problem: Menyediakan materi visual yang rapi, bersih, berformat vektor, dan sesuai dengan kebutuhan gaya visual tim produksi animasi 2D.
Solution: Menggambar dan mengekspor tiga (3) aset visual berbasis vektor menggunakan Inkscape dengan struktur layer terorganisir untuk mempermudah penganimasian.
Kontribusi Saya: Menggambar sketsa dan melakukan penarikan garis vektor (tracing) 3 aset visual orisinal menggunakan Inkscape.
